# Lumina Tech

Landing Page desenvolvida para a avaliação N2 da disciplina de Desenvolvimento Web.

## Sobre o projeto

A Lumina Tech é uma empresa fictícia especializada em soluções de energia sustentável, oferecendo sistemas de energia solar inteligente, monitoramento energético e consultoria especializada.

O objetivo do projeto é desenvolver uma landing page moderna, responsiva e intuitiva, focada na apresentação da marca, conversão de clientes e divulgação de soluções sustentáveis para empresas.

O site foi desenvolvido utilizando HTML5 e CSS3, com foco em design moderno, experiência do usuário e responsividade para diferentes dispositivos.

---

## Funcionalidades

- Header fixo com menu de navegação
- Menu mobile responsivo
- Hero section com chamada principal
- Seção de desafios do mercado
- Seção de soluções oferecidas
- Benefícios da empresa
- Área de estatísticas e resultados
- Depoimentos de clientes
- Processo em etapas
- Formulário de orçamento
- Footer completo
- Layout totalmente responsivo
- Efeitos hover e animações visuais
